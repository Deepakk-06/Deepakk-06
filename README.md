# Hi, I'm Deepak K

Electrical and Electronics Engineering student building robotics systems that connect software, sensors, and real-world motion.

I work across ROS 2, autonomous navigation, LiDAR-based mapping, embedded systems, computer vision, and control algorithms. My focus is simple: build robots that can sense, decide, and move reliably.

## What I'm Building

- ROS 2 autonomous navigation systems with LiDAR, SLAM, localization, and Nav2 workflows
- Model Predictive Control for smoother robot trajectory tracking and obstacle-aware motion
- micro-ROS based human-robot interaction pipelines for embedded robot control
- YOLO and OpenCV based computer vision projects for detection and mapping
- PID control systems for line-following and mobile robot behavior
