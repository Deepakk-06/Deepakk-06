<h2 align="center">🚀 About Me</h2>

**Deepak K**, here — an EEE student building robots that actually run on real hardware, not just in Gazebo.

I work across **ROS 2 navigation, SLAM/localization, Model Predictive Control, embedded systems, and computer vision**. My current flagship is an 18-DOF hexapod with custom inverse kinematics and gait generation, alongside a SLAM robot deployed on a Raspberry Pi 4 and an MPC framework for smoother, obstacle-aware trajectory tracking.

Currently sharpening: **Nav2 tuning, MPC, and cleaner end-to-end robot documentation.**
